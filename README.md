Mesh I/O for Python.

**maillages** is a Python library for mesh conversion, named as a play on the French word for *meshes* and the literal translation of *mesh I/O* (**maillage** **E**ntrée/**S**ortie).
It is designed as a spiritual successor to [**meshio**](https://github.com/nschloe/meshio), providing a modern and lightweight interface for reading and writing unstructured mesh formats in Python.
